# 账号、同步和隐私

## 已实现

- scrypt 加盐密码哈希；随机会话令牌仅以哈希落库。
- HTTPS 部署启用 Secure、HttpOnly、SameSite=Lax Cookie；写接口校验 CSRF。
- 注册不接受客户端指定管理员角色；管理员依靠服务器一次性初始化令牌。
- 恢复码随机生成、哈希存储。重置密码轮换恢复码并撤销该账号的现有会话。
- 邮箱登录 / 注册 / 恢复 / 好友申请限速；完整邮箱匹配，不开放邮箱搜索列表。
- 好友关系需要接收方确认；榜单不返回好友邮箱、私人笔记或错题。
- 挑战题目的正确选项不在题面接口返回；答题后才返回解释；计星事务具有唯一约束。
- 云端私有媒体需要登录；Service Worker 不缓存账号 API 或私有资料。

## 必须理解的边界

邮箱没有验证，所以不能证明本人拥有该邮箱。有人可能先注册别人的邮箱。适合互相认识、可以线下核实的小圈子；扩展到陌生公众前应接入邮件验证、滥用防护及管理审计。

开放注册时，任何完成注册的人都可访问共享学习资料；登录保护不是邀请制访问控制。不要公开传播私人资料站入口。若需严格限制为家人同学，应关闭公开注册并使用邀请，或增加注册邀请码。

云同步是服务端持久化，不是实时协同编辑：更换设备登录后加载云端状态；同一字段被两台设备同时修改时，普通学习状态采用最后一次成功保存的值。星星挑战按服务器题号串行推进，重试不会重复计星。

断网期间的答题不是服务器确认结果，不保证离线写入队列；恢复联网后继续。不要宣称网页提示本身就是完成同步。

排行榜不是严格反作弊考试。题库可查、浏览器可自动化；服务器只保证不能直接提交虚假的星星或修改 correct 字段刷分。

默认公开注册最多 1000 个账号是可调保护阈值，不是容量承诺。家庭私有部署请不要在公共介绍页宣传商业教材下载。

## 运维

- 密钥、.env、数据库、备份、日志不进入 Git。
- 同盘备份不能防止整机/磁盘丢失，请另做加密异地备份。
- 当前无邮件服务，恢复码丢失须管理员线下核验后处理；不要根据声称的邮箱直接重置账号。
- Ubuntu 小服务器不部署大型 ASR 模型；已有音频、字幕、例句不依赖在线模型运行。
- 发现问题时不要在公开 Issue 粘贴数据库、会话、恢复码或 SSH 密钥。
