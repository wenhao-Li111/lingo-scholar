# 电脑、安卓和 iPhone 怎么使用

三个平台使用同一套学习网站和云端账号。推荐收藏 [GitHub 网站入口](https://wenhao-li111.github.io/lingo-scholar/)。

| 平台 | 使用方式 | 当前形态 |
|---|---|---|
| 电脑网页 | 浏览器进入网站，注册或登录 | 已上线的网页应用 |
| 安卓手机 | 浏览器 / 添加到主屏幕 / APK | APK 是使用系统浏览器引擎的轻量安装版 |
| iPhone / iPad | Safari / 添加到主屏幕 | 网页应用，不是 App Store 或 TestFlight 安装包 |

## 电脑网页端

1. 打开 [网站入口](https://wenhao-li111.github.io/lingo-scholar/)，点击「进入学习网站」。
2. 用邮箱注册，保存恢复码；已有账号直接登录。
3. 首页学习每日词汇，或从导航进入词库、听力、阅读、写作和真题。

建议使用更新后的 Chrome、Edge 或 Safari。电脑上不需要下载客户端；支持安装网页应用的浏览器也可通过地址栏安装按钮安装。

## 安卓：直接使用网页或安装到主屏幕

1. 用 Chrome 等浏览器打开网站入口，再进入实际学习站。
2. 在浏览器菜单选择「安装应用」或「添加到主屏幕」（文字随浏览器版本变化）。
3. 从桌面「听词研习室」图标打开，用原来的邮箱登录。

如果在微信、QQ 内打开后出现朗读、登录或安装问题，请选择「在浏览器中打开」。

## iPhone / iPad：添加到主屏幕

1. 用 **Safari** 打开网站入口，点击「进入学习网站」。
2. **等待实际学习站打开后**，点 Safari 的分享按钮，选择「添加到主屏幕」。不要停在 GitHub 介绍页操作，否则添加的只是介绍页。
3. 如果系统显示「作为网页 App 打开」，保持开启，再点「添加」。
4. 从主屏幕图标进入；如提示登录，使用同一邮箱即可。

菜单位置可能随 iOS 版本改变，可参考 [Apple 官方操作说明](https://support.apple.com/guide/iphone/open-as-web-app-iphea86e5236/ios)。

目前没有 `.ipa`、App Store 或 TestFlight 版本，也不需要安装描述文件或信任企业证书。原生 iOS 分发需要另行配置 Apple 开发者签名和发布流程。

## 更新版本：需要重新下载吗？

**大部分学习功能更新不需要重装，但只修改 GitHub 代码不会自动更新学习服务器。**

| 更新内容 | 用户怎么获取 | 是否重新安装 |
|---|---|---|
| 网页、词汇练习、听读界面 | 维护者部署到云服务器后，联网刷新或关闭再打开学习页 | 不需要 |
| 安卓 APK 内打开的学习页面 | 与网页版相同，加载云服务器上已部署的新版本 | 不需要更新 APK |
| iOS 主屏幕网页应用 | 联网重新打开；必要时关闭后再打开 | 不需要重新添加主屏幕图标 |
| 安卓原生启动页、图标或内置服务器地址 | 获取维护者签名的新 APK，由 Android 确认覆盖安装 | 需要新版安装包 |
| GitHub 介绍页和下载文件 | 维护者更新 `site/` 并推送到 main 后，Pages 自动发布 | 刷新入口页即可 |

目前**没有 APK「检查更新 / 应用内下载升级」功能**，也不会静默安装。若 APK 本身需要升级，仍需从项目下载入口获取新版；后续可以增加应用内更新提示和下载入口，但覆盖安装仍要用户确认，且必须沿用原来的签名密钥。

网页已包含 Service Worker 更新提示，检测到新的 Service Worker 时会提示刷新；它不是完整的版本检测系统，不保证每次改代码都出现提示。学习过程中建议先等待当前进度保存，再刷新页面。

当前 GitHub 自动化只负责代码检查、安卓未签名构建检查和 Pages 入口发布，**尚未配置 GitHub → 腾讯云学习服务器自动部署**。所以「GitHub 有新提交」与「三端学习页面已更新」是两件事。教材和用户数据也不随公开仓库提交自动覆盖。

## 云端同步、音频与离线范围

- 同一邮箱账号可在三端加载自己的进度、收藏、听读位置和星星；恢复码不是登录密码，不要分享。
- 切换设备前保持联网并等待保存完成。多设备同时修改同一状态，以最后成功保存为准。
- 离线可能只能打开已缓存的界面；登录、资料加载、挑战结算和同步依赖网络，不保证离线答题补交。
- 点击播放后再听音频；朗读声音与英文语音包受浏览器及设备影响。息屏、切后台后持续播放不作保证。
- 现有页面做过手机尺寸模拟检查，但并不代表已通过真实 iPhone、所有安卓品牌或所有浏览器的验收。

## 常见问题

**为什么不是一直显示 github.io？** GitHub Pages 是介绍与入口，学习站和账号数据运行在独立云服务器。进入学习后显示实际 HTTPS 服务器地址是正常的。

**无法进入网站？** 检查网络、浏览器是否更新；不要绕过证书错误。若服务器维护，三个平台都可能暂时不可用。

**卸载后进度还在吗？** 成功保存到云端的记录仍在账号中；重新登录即可加载。未同步的本地状态可能丢失。
