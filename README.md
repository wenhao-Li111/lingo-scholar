# Lingo Scholar · 听词研习室

**每天 20 个词，把单词记进句子，把进步留在每一天。**

听词研习室是一个把背单词、听力、阅读资料和好友挑战放在一起的雅思学习网站。电脑、安卓手机、iPhone 都能通过浏览器使用，无需安装软件。

## 从这里开始

收藏我们的 [GitHub 网站入口](https://wenhao-li111.github.io/lingo-scholar/)，点击「进入学习网站」即可开始。
入口页不需要登录；进入学习系统后，用邮箱注册账号，并妥善保存第一次显示的恢复码。

> GitHub 入口是介绍与导航页；进入学习系统后会跳转至独立的 HTTPS 学习站点。邮箱目前不发送验证邮件，找回密码需要恢复码。

### 选择你的设备

| 设备 | 如何开始 |
|---|---|
| 电脑网页 | 打开入口 → 进入学习网站 → 邮箱登录 |
| 安卓 | [下载 APK · 1.0.0](https://wenhao-li111.github.io/lingo-scholar/downloads/lingo-scholar-1.0.0.apk)，或浏览器添加到主屏幕 |
| iPhone / iPad | Safari 进入学习站 → 分享 → 添加到主屏幕 |

查看 [三端使用与安装指南](docs/PLATFORMS.md)。安卓 APK 使用系统浏览器引擎承载学习功能；iOS 目前提供主屏幕网页应用，不是 App Store 原生 App。三端共享同一个云端账号。

**更新要重新安装吗？** 学习网页部署到云服务器后，三端联网刷新即可使用，通常不需要重装。仅在安卓原生安装包本身变化时才需要新版 APK；目前没有 APK 应用内升级功能。只在 GitHub 提交代码，不会自动部署学习服务器。详见 [版本更新说明](docs/PLATFORMS.md#更新版本需要重新下载吗)。

## 不只是认识单词，更要会在语境中使用

### 每日词汇：打开就能学

每天从一个主题词库随机抽取 20 个词，当天保持固定。首页就能开始学习，不用先在层层菜单里找课程。

- **词义回想**：四个中文选项，选择正确释义，而不是只点「认识 / 不认识」。
- **看义拼写**：根据中文释义，写出英文单词。
- **听音默写**：听发音，再输入单词。
- **词性和音标**：释义标注 `n.`、`v.`、`adj.` 等词性，帮助区分不同用法。
- **答完看例句**：单词在例句中高亮，同时显示中文翻译，让记忆不止停在词义上。

想多学一些？进入「词汇练习」选择主题词库。卡片上的彩色进度条会显示已学数量，离开再回来可以继续上次的练习。

### 听力：边听边对照，不必反复跳转

在站内选择听力材料、播放、暂停或拖动进度。需要帮助时，展开原文和中文译文，随着播放查看当前句的位置，再回听没有听清的部分。

听力位置、笔记和收藏保存在账号中。建议先独立听一遍，再打开原文核对。字幕和译文包含自动处理内容，遇到疑问请结合原音频与原书判断。

### 阅读、写作与真题：放在同一个学习空间

通过底部导航进入阅读、写作和真题资料。PDF 可以直接在网页中翻阅，不必为每份资料另开外部网站；阅读位置、收藏与笔记也能保存。

写作模块目前以资料阅读和练习参考为主，**不是自动作文评分服务**。各站点可用的资料取决于其收录内容，GitHub 仓库不提供整套商业教材下载。

### 复习与收藏：找到真正需要再练的内容

词汇练习可按「薄弱词」或「到期词」筛选。主题词库中的普通复习安排为：答错后约 1 天再练，答对后约 7 天再练；旧的「模糊」记录约 3 天后复习。

喜欢的单词、听力和阅读资料可以加入收藏，在「收藏」页按类别找回。好友星星挑战与普通词库复习分别记录，不会因为自由练习答错就扣星。

## 和熟悉的朋友一起积累星星

点击页面顶部的「★ · 好友」，输入朋友的完整邮箱发送申请。对方接受后，就能在本周榜和累计榜上看到彼此的星星。

每组挑战 20 个词，按第一次作答的正确率结算：

| 正确率 | 星星 |
|---|---:|
| 95–100% | +10 ★ |
| 85–94% | +7 ★ |
| 70–84% | +4 ★ |
| 60–69% | +1 ★ |
| 低于 60% | −2 ★，总数不低于 0 |

每天最多 5 组计星挑战，未完成的挑战可以稍后继续。退出、断网和普通自由练习本身不扣星。周榜按北京时间每周一重新统计，累计星星保留；同分并列。

好友只能看到用于竞争的昵称和星星，不能因此查看你的私人笔记。邮箱未经验证，添加好友前请通过聊天或线下确认对方身份。

## 换一台设备，继续自己的进度

用同一邮箱登录，词库进度、收藏、阅读位置、听力位置和星星会从云端加载。

- **电脑**：适合看资料、做阅读和集中练习。
- **手机**：利用零碎时间背词、听音频；可通过浏览器「添加到主屏幕」快捷打开。
- **切换设备前**：保持联网，等待当前操作保存完成。

这不是实时协同编辑工具：同时在两台设备修改同一项普通学习状态时，以最后成功保存的内容为准。离线答题不保证自动补交；恢复网络后请核对进度。

## 常见问题

**需要下载 App 吗？**  
不需要。网页可以直接使用；安卓另提供轻量安装版，iOS 可添加到主屏幕。它们不是离线教材包，也未上架应用商店。具体步骤见 [三端指南](docs/PLATFORMS.md)，不同设备的朗读声音可能不同。

**忘记密码怎么办？**  
在登录页选择「忘记密码」，输入邮箱与恢复码。没有邮件找回服务，请不要把恢复码发给好友。

**为什么开源仓库只有演示词库？**  
代码开源不代表教材可以再次分发。仓库提供 40 词原创演示；学习站点的词库和资料单独维护，不把用户数据、私人教材或服务密钥放进 GitHub。

**能自动给雅思成绩打分吗？**  
不能。星星是词汇练习的激励，不代表雅思分数；本项目不提供官方成绩预测。
